# Pazzo's Italian — Ocean Beach, San Diego

Artisanal coastal Italian restaurant website for Pazzo's Italian at 2163 Abbott St, San Diego, CA 92107.

## Features
- Full editorial hero and story sections
- Interactive curated seasonal menu (Antipasti, Pasta Fresca, Secondi & Mare, Dolci)
- Wine & cocktails showcase
- Dining experience highlights (Candlelit Room, Ocean Breeze Patio, Chef's Counter)
- Inline and modal reservation system with confirmation
- Mobile-responsive with glassmorphic navigation
- Tailwind CSS + custom animations

## Tech
Static HTML, Tailwind CSS (CDN), vanilla JavaScript. No build step required.

## Deploy
Enable GitHub Pages from the main branch root, or open `index.html` locally.
